# คู่มือผู้ใช้ Camfrog

English version: `USER-MANUAL-EN.md`.

หกแอป หนึ่งคู่มือ

แอป: `room-control`, `chat-im-private`, `status-random`, `status-marquee`, `im-autoreply`, `music-dj`, `web-status` ทุกแอปใช้ได้เฉพาะ Windows และต้องเปิด Camfrog ไว้ ยกเว้น `web-status` ที่ทำงานผ่านเว็บไซต์

**อัปเดต** ทุกแอปตรวจ GitHub release ตอนเปิด (ขึ้น banner เฉพาะเมื่อมีเวอร์ชันใหม่) และมีปุ่ม **Check for updates** ส่วน CLI ใช้คำสั่ง `<app> update` การอัปเดตดาวน์โหลดเฉพาะไฟล์ของแอปนั้น ตรวจกับ `SHA256SUMS.txt` ของ release แล้วติดตั้งตอนปิดแอป (`<app>.new` กับ `camfrog-update.cmd` เป็นตัวสลับไฟล์) ไม่ต้องมีบัญชีหรือโทเคน และไม่ส่งข้อมูลอะไรขึ้น GitHub เลย เผยแพร่ release ด้วย `python tools/release.py`

## 1. ติดตั้ง

1. ติดตั้ง Python 64-bit รุ่น 3.12 หรือ 3.13
2. รัน `doctor.bat` ก่อน เพื่อตรวจ Python และทดสอบการโหลด `pywin32`
3. ดับเบิลคลิก `build.bat` (หรือ `full-build.bat` สำหรับทุกแอปรวมแอป LINE) ไฟล์ exe จะอยู่ใน `dist\<app>\`
4. ถ้า build ขึ้น `pywin32 ... no matching distribution` แปลว่า Python รุ่นนั้นไม่มี wheel ให้ติดตั้ง Python 3.13 แบบ 64-bit ลบ `.venv` แล้วรันใหม่

## 2. เริ่มใช้ครั้งแรก

1. เปิด Camfrog แล้วเข้าห้อง (อย่าย่อลง tray)
2. เปิดแอปแล้วกด **Setup → Auto-detect** (แอป room/im) หรือ **Discover controls** (แอป status/private-chat/web) เพื่อให้โปรแกรมหา control ให้อัตโนมัติ
3. เปิด `dry_run` ไว้ก่อนเสมอขณะทดสอบ โหมดนี้แค่บันทึกว่าจะส่งอะไร ไม่ส่งจริง
4. เปิดโหมดจริงเมื่อพร้อมแล้วเท่านั้น: ช่อง **LIVE** / **Send statuses live to Camfrog** / **Send live**

## 3. ควบคุมห้อง

- ตั้งนิคของตัวเอง (`My nickname`) จำเป็นสำหรับโหมดจริง
- **Window title regex** ใช้เลือกว่าจะควบคุมหน้าต่าง Camfrog ใด
- กฎตอบอัตโนมัติ: รูปแบบ regex, ข้อความตอบ, คูลดาวน์รายคน, ตอบเฉพาะเมื่อถูกเรียกชื่อ, ภาษา (`th`/`en`) ทดสอบด้วย **Test rule** ก่อนเปิดจริง
- **Save & Start** เริ่มบอทเบื้องหลัง **Stop** หยุด ปิดหน้าต่างไม่ทำให้บอทหยุด
- กันสแปม: ไม่ตอบข้อความที่มีลิงก์ (ค่าเริ่มต้น `ignore_links`) และข้ามตาม `skip_patterns`

## 4. ตอบแชทส่วนตัว

- แอปแยก config แยกกฎ การตอบในห้องไม่ยุ่งกับแชทส่วนตัว
- **ต้องระบุรายชื่อเพื่อน** (`only_nicknames`) ตอบเฉพาะคนที่อยู่ในรายชื่อ
- เพดานเข้มกว่าปกติ (ค่าเริ่มต้น: ตอบเพื่อนคนละ 1 ครั้งต่อชั่วโมง วันละ 3 ครั้ง รวมชั่วโมงละ 10 ครั้ง) ทุกคำตอบขึ้นต้นด้วย `[auto] ` และจะไม่ตอบบรรทัดที่มีคำนำหน้านี้
- หน้าต่างที่เปิดอยู่ก่อนบอทเริ่มจะไม่ถูกตอบ

## 5. จัดการหน้าต่างแชทส่วนตัว

- แสดงรายชื่อหน้าต่างแชทส่วนตัวที่เปิดอยู่ **Refresh** โหลดใหม่ ดับเบิลคลิกหรือ **Activate selected** เพื่อโฟกัส ไม่มีการอ่านหรือส่งข้อความ
- ตัวกรองชื่อหน้าต่าง (regex) กับจำนวนสูงสุดช่วยจำกัดรายชื่อ **Save filters** บันทึกลง config ของแอปนี้
- **Discover controls** ดึงรายการ control ลง `controls.txt` เพื่อตั้ง selector

## 6. สถานะสุ่ม

- สิบช่องข้อความ ระบบสุ่มสถานะจากรายการนี้
- **Switch every** (วินาที อย่างน้อย 30) ระยะเวลาก่อนเปลี่ยนสถานะ บันทึกลง `status.interval_seconds`
- **Start** เริ่มสลับทันที **Stop** หยุด ข้อมูลอยู่ใน `random-data\` แยกจาก Marquee

## 7. สถานะเลื่อน

- ข้อความยาวเลื่อนผ่านหน้าต่างกว้าง `width` ตัวอักษร: **Step** (วินาทีต่อเฟรม ขั้นต่ำ 0.5) **Stride** (กลุ่มอักษรต่อเฟรม) **Loop** (วนไม่หยุด) ถ้าปิด **Scroll** (ค่าเริ่มต้น) จะส่งทีละ 1 บรรทัดเต็มต่อรอบ วน 1..N
- ทุกเฟรมคือการเปลี่ยน status จริง ตั้งให้ช้าและน้อยเฟรม เริ่มด้วย dry-run เสมอ
- ปลอดภัยภาษาไทย: ไม่ตัดสระ/วรรณยุกต์ ไม่สร้างเฟรมว่าง

## 8. ประวัติ ตารางเวลา ภาษา

- ทุก status ที่ตั้งถูกเก็บลงประวัติ ถ้าเปิด `use_as_source` จะสลับเลือกจากประวัตินั้น (`rotate`/`random`/`most_used`)
- ตั้ง pool ต่างกันตามช่วงเวลาของวัน (`status.schedules`) ระบุ `start`/`end` เป็น `HH:MM`
- `status.language_cycle: ["th","en"]` สลับไทย/อังกฤษทุกครั้งที่เปลี่ยน status รายการสถานะเป็นคู่ `{th, en}` ได้
- `"language": "auto"` ตามภาษาหน้าจอ Windows อัตโนมัติ

## 9. ดีเจเพลง

- บอทห้องที่เล่นเพลงได้พร้อมรับคำขอจากแชท ต้องเปิด Camfrog และเปิด `autoreply` (ดีเจใช้ระบบอ่านแชทนี้) แล้วตั้ง `dj.enabled`
- คำสั่งในแชท ค่าเริ่มต้นนำหน้าด้วย `!`: `!request <เพลง>` (หรือ `!req`, `!song`), `!queue`, `!current` (หรือ `!np`), `!skip`, `!help` หน้าต่างคิวในแอปแสดงสถานะเดียวกับไฟล์ โดยมีปุ่มเจ้าของบอทคือ **ข้ามเพลงปัจจุบัน** / **ล้างคิว**
- คำขอแรกเล่นทันที เพลงถัดไปเข้าคิว (จำกัดต่อคนตาม `max_per_user` เพลงซ้ำหรือเพลงที่กำลังเล่นจะถูกปฏิเสธ) คำสั่ง `!skip` ใช้ได้กับผู้ขอหรือเจ้าของบอท
- โฟลเดอร์เพลง: ใส่ไฟล์ `.wav` ไว้ แล้ว `!request` จะจับคู่จากชื่อไฟล์ (บางส่วนของชื่อก็ได้ ไม่สนตัวใหญ่เล็ก)
- **Audio backend** `chat` (ค่าเริ่มต้น) จะประกาศในแชทอย่างเดียว ส่วน `local` จะเล่นไฟล์ `.wav` บนเครื่องนี้เพิ่ม โดยเริ่มเพลงถัดได้เองเมื่อเพลงปัจจุบันจบ เพื่อให้ห้องได้ยิน ต้องส่งเสียงของเครื่องนี้เข้า input ของ Camfrog ด้วย virtual cable หรือ "Stereo Mix" ก่อน และ MP3 ต้องแปลงเป็น WAV
- เริ่มแบบ dry-run ก่อน: บอทจะแค่บันอกว่าจะประกาศอะไร คำขอเพลงยังเข้าคิว แต่ไม่พิมพ์อะไรเข้าห้อง

## 10. สถานะผ่านเว็บ (รุ่นทดลอง)

สถานะ: รู้ขั้นตอน login แล้ว และดึง endpoint อัปเดตสถานะได้จากหน้า home.php ที่ล็อกอินอยู่ (POST `{status, csrf}` ไป `/ajax/update_status.php`) แต่ยังกั้นไว้ การส่งครั้งแรกต้องใส่ `--confirm-update`
- ส่วน **Account (stored encrypted)** ใน GUI: กรอกนิคกับรหัสผ่านแล้วกด **Save encrypted** ข้อมูลจะถูกผนวกด้วย Windows DPAPIเก็บไว้ที่ `.env.enc` ถอดได้เฉพาะผู้ใช้ Windows คนนี้ ไฟล์ที่คัดลอกไปใช้ที่อื่นใช้ไม่ได้ จึงไม่มีข้อความplaintextบนดิสก์ และไม่มีการบันทึกรหัสผ่านใน log หรือแสดงผล หลังจากบันทึกแล้ว CLI ไม่ต้องใส่ `--login` หรือรหัสผ่านอีก (อ่านจาก `.env.enc` ในหน่วยความจำ) โดย `.env.enc` ถูก ignore โดย Git

- ไม่ใส่ argument เปิด GUI ใส่ argument ใช้ CLI (`web-status.exe --login Seaza --status "..."`) ค่าเริ่มต้นคือ dry-run ไม่มีการต่อเน็ต
- **Preview plan** แสดงสิ่งที่จะทำ **Probe session** ตรวจ session จากไฟล์ cookie อย่างเดียว (โชว์แค่จำนวน/โดเมน ไม่โชว์ค่า) ปุ่ม **Chrome** ดึง session จากที่เก็บ cookie ของ Chrome ให้อัตโนมัติ ไม่ต้องส่งออกไฟล์ ไม่บันทึกอะไรลงดิสก์ แต่ Chrome ล็อกไฟล์นั้นไว้ขณะรัน (การแชร์ไฟล์ถูกปฏิเสธ) ปุ่ม **Chrome** จึงต้องใช้ตอนปิด Chrome (เครื่องมือจะบอกเรื่องนี้ชัดเจนแทนการ error สับสน) ส่วนการส่งออก cookies.txt หรือบัญชีที่บันทึกแอบได้ใช้ได้ทั้งสอง 상태
- รหัสผ่าน: ถามตอนรันเท่านั้น (CLI) หรือช่องปกปิด (GUI) ใช้ครั้งเดียว ลบทันที ไม่บันทึก ไม่พยายามเลี่ยง CAPTCHA — ถ้าเซิร์ฟเวอร์ตอบ `captcha` โปรแกรมหยุด
- **Start** สลับ pool หลายบรรทัดอัตโนมัติทุก N วินาที โหมดจริงต้องมีอย่างใดอย่างหนึ่ง: ไฟล์ cookie, ปุ่ม Chrome (ปิด Chrome), หรือ **บัญชีที่บันทึกไว้** — ส่วน Account ด้านบนง่ายที่สุด ไม่ต้องใช้ Chrome รหัสผ่านถอดแอบในหน่วยความจำเท่านั้น กดตัวเลือก **Send live** แล้วกด **Start** ครั้งแรกจะถามยืนยันก่อนส่งจริง **Stop** หยุดทันที
- ส่งออกเอง (ทางสำรอง): "Get cookies.txt LOCALLY" เก็บไว้นอก repo (`*cookies*.txt` ไม่มีวันถูก commit) ห้ามวางรหัสผ่านหรือค่า cookie ในแชท issue หรือไฟล์

## 11. เบื้องหลัง log ไฟล์

- Room/IM: ปุ่ม GUI **Save & Start** / **Stop** หรือคำสั่ง CLI `start` / `state` / `stop` (แบบซ่อน ไม่มีหน้าต่าง) สถานะ: ปุ่ม **Start**/**Stop** ของตัวเองกับ worker ที่มากับแอป
- แต่ละแอปบันทึก log ข้าง config ตัวเอง (source CLI ใช้ `camfrog_auto.log`) แก้ `config.json` ตอนรันได้ ค่าถูกต้องมีผลใน ~3 วินาที ค่าผิดถูกปฏิเสธและ log ไว้
- ทุกครั้งที่ส่งจะดึง Camfrog ขึ้นมาชั่วครู่ กด Enter แล้วคืนโฟกัสเดิม Camfrog ต้องเปิดอยู่ (ย่อไว้ได้เฉพาะเมื่อ control ยังเข้าถึงได้ — ตรวจด้วย Discover)

## 12. แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| `pywin32 ... no matching distribution` | ติดตั้ง Python 3.13 64-bit ลบ `.venv` รัน `build.bat` ใหม่ |
| Auto-detect หาไม่เจอ | เปิดห้องแชทให้เห็นหน้าต่างแล้วลองใหม่ แล้วใช้ Discover controls |
| error `requirements.txt (line 1)` พูดถึงแต่ pywinauto | ใช้ไฟล์เก่า แตก zip ล่าสุดลงโฟลเดอร์ใหม่ |
| สถานะไม่ส่ง (แอปสถานะ) | เปิด **Send statuses live to Camfrog** ค่าเริ่มต้นคือโหมดทดลอง |
| เสียง error ทุกครั้งที่เปลี่ยนสถานะ | ลอง **combo Enter (test)** ตรวจด้วย Apply Now ก่อนใช้ marquee |
| ควบคุมหน้าต่างผิด/เก่า | แก้ **Window title regex** แล้ว detect ใหม่ |
| Explorer โชว์ไอคอนเก่าหลัง build | cache ไอคอน Windows ย้าย/เปลี่ยนชื่อ exe หรือรีสตาร์ท Explorer |

## 13. ความปลอดภัย

- `dry_run` เปิดเป็นค่าเริ่มต้น คำตอบถูกจำกัดความถี่ (คูลดาวน์รายคน ช่องว่างรวม เพดานรายชั่วโมง)
- บรรทัดที่ไม่ใช่รูป `ชื่อ: ข้อความ` ถูกข้าม คำตอบที่ขึ้นต้นด้วย `/` ถูกบล็อก ไม่มีการเตะอัตโนมัติ
- ห้าม commit รหัสผ่าน cookie token หรือข้อมูลส่วนตัว ไฟล์ cookie อยู่นอก repo เสมอ
- ตรวจเงื่อนไข Camfrog และกฎห้องก่อนเปิดระบบอัตโนมัติ แจ้งช่องโหว่แบบส่วนตัวตาม `SECURITY.md`
